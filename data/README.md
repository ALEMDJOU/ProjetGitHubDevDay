## What is committed here

`raw/avocado_features.csv` (~1.3 MB) is **derived** from the original dataset (a change under
CC BY 4.0): one row per real photo, with the official labels and metadata, plus colour
statistics computed from the pixels of the fruit by
[`scripts/extract_features.py`](../scripts/extract_features.py). Nothing is synthetic or generated.

The raw archive (~418 MB) is **not** committed and is **not** needed by CI.

**Local photos for the Streamlit UI:** extract the JPEGs (flat, no sub-folder) into
`data/images/`, e.g. `data/images/T20_d05_001_a_3.jpg`. This folder is git-ignored and
docker-ignored. One photo, `tests/fixtures/T20_d05_001_a_3.jpg`, is committed for the tests.

## Schema

| Column | Type | Description |
|---|---|---|
| `file_name` | str | Original photo name, e.g. `T20_d05_001_a_3` (group, day, sample, side, stage) |
| `sample` | int | Avocado ID (1–478). Used to group the train/test split. |
| `storage_group` | str | `T10` = 10 °C / 85% RH, `T20` = 20 °C / 85% RH, `Tam` = ambient |
| `day` | int | Day of the experiment the photo was taken (1–26) |
| `ripening_index` | int | **Target.** 1 underripe, 2 breaking, 3 ripe (first stage), 4 ripe (second stage), 5 overripe |
| `l_mean`, `l_std` | float | Mean / std of CIE Lab lightness L* over fruit pixels |
| `a_mean`, `a_std` | float | Mean / std of a* (negative = green, positive = red) |
| `b_mean`, `b_std` | float | Mean / std of b* (negative = blue, positive = yellow) |
| `dark_fraction` | float | Share of fruit pixels with L* < 30 (dark skin) |
| `fruit_fraction` | float | Share of the (resized 200×200) image covered by the fruit |

Fruit pixels are everything that is not the white background (value ≥ 0.60 and
saturation ≤ 0.18 in HSV).

## Rebuild the CSV from scratch

```bash
pip install -r scripts/requirements-extract.txt
curl -L -o 3xd9n945v8-1.zip "https://data.mendeley.com/public-api/zip/3xd9n945v8/download/1"
python scripts/extract_features.py 3xd9n945v8-1.zip   # ~2.5 min on a laptop CPU
sha256sum data/raw/avocado_features.csv               # should match the table above
```
